## AI-ассистент для казначейской функции

#### В данном репозитории вы можете найти исходный код клиентской приложения, разработанного в рамках кейс-чемпионата Finopolis2025 - трек "Искусственный интеллект", кейс "AI-ассистент для казначейской функции"

https://hack.uwu-devcrew.ru (ссылка нонче нерабочая)

Приложение представляет из себя многостраничный дашборд с внедренным искусственным интеллектом, который принимает и наглядно отображает информацию о финансовом состоянии компании, а также предоставляет сценарную аналитику (прогнозирование) для трех исходов - нейтральный, положительный, и отрицательный. AI-ассистент получает данные о компании, и на их основе даёт советы по финансовым вопросам. Пользователь импортирует свои KPI в систему, и искусственный интеллект на их базе предоставляет развернутую аналитику в графическом представлении, и ответит на любые вопросы клиента, связанные с бизнесом, например, про увеличение показателей или размещение акций. Клиентская часть разработана с помощью библиотеки ReactJS, библиотеки готовых компонентов React Suite и препроцессора Sass. Управление состоянием приложения реализовано с помощью Redux + Redux Toolkit. Отображение графиков было реализовано с помощью библиотеки Chart.js. ИИ-ассистент запоминает информацию о делах компании с помощью RAG, векторного проебразования и хранения векторного представления в БД Qdrant.
